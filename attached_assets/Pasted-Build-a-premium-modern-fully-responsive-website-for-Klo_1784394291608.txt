Build a premium, modern, fully responsive website for Kloud Diagnostics & Imaging, a prominent diagnostic testing, blood collection, and medical imaging center with multiple branches across Mumbai, India. This is a real healthcare business — the site must feel trustworthy, clean, clinical-but-warm, and high-end. Think "Apple-level polish meets a diagnostic lab." I want this to genuinely impress a client, so prioritize visual quality, smooth interactions, and a premium feel over generic templates.

1. TECH STACK

Use React + Tailwind CSS for the frontend, with Framer Motion for animations. Use a lightweight Node/Express backend (or Replit DB) only where needed for the file upload and search functionality. Fully responsive — mobile-first, but should look excellent on desktop too. Fast load times, clean component structure.

2. BRAND & VISUAL DESIGN

Color palette (use CSS variables so it's easy to adjust):


Primary: Deep Teal #0B7A75 (trust, clinical, calm — avoid generic hospital red/blue)
Secondary: Soft Aqua/Mint #5FD0C4 (accents, hover states, highlights)
Deep accent / CTA: Coral-Orange #FF6B4A (used sparingly for "Book Now," "Upload Prescription," urgent buttons — creates contrast against the teal)
Neutral background: Off-white #F7FAF9 and pure white #FFFFFF for cards
Dark text: Charcoal #1E2A2E (not pure black — softer, easier to read)
Success/positive: #3BB273 — Warning/alert: #F2A93B
Use soft gradients (teal → aqua) sparingly in hero backgrounds and section dividers, not everywhere.


Typography:


Headings: "Poppins" or "Plus Jakarta Sans" (Google Fonts) — semi-bold/bold, confident, modern, slightly rounded — feels professional but approachable, not sterile.
Body text: "Inter" or "Nunito Sans" (Google Fonts) — highly legible at small sizes, good for medical detail text, test names, disclaimers.
Use a clear type scale (e.g., H1 48px/desktop, H2 36px, H3 24px, body 16px, small print 13px). Generous line-height for readability (1.6 for body copy).


Effects & animation direction (tasteful, not gimmicky):


Smooth scroll-reveal animations (fade + slight upward slide) as sections enter viewport
Subtle parallax on hero background shapes/blobs
Hover states: cards lift slightly with soft shadow + border-color transition on hover
Buttons: smooth scale (1.03x) + color shift on hover, with a satisfying press/tap animation
Animated counters for stats (e.g., "500,000+ Tests Conducted," "15+ Locations," "20+ Years")
Soft skeleton-loading shimmer while search results or reports load
Sticky header that condenses (shrinks height, adds shadow) on scroll
Micro-interaction on successful file upload (checkmark animation, gentle confetti-free success state)
A subtle animated pulse/heartbeat-line SVG motif used decoratively in the hero (medical feel without being cheesy)
Floating WhatsApp + Call Now button, bottom-right, on all pages, with a subtle pulse animation to draw attention

5. HERO SECTION (TOP OF HOMEPAGE) — CRITICAL FEATURE


Large, confident headline (e.g., "Accurate Diagnostics. Trusted Across Mumbai.") with a short supporting line about NABL-accredited labs, fast reports, and home collection.
A large, prominent search bar must sit at the very top of the hero — this is the primary interaction of the homepage. It should:

Have placeholder text like "Search for a test, package, or health concern (e.g., CBC, Thyroid, Full Body Checkup)"
Show a live autocomplete dropdown as the user types, listing matching individual tests AND health packages, each with a price and an "Add" button
Include a small filter toggle nearby: "All | Blood Tests | Imaging | Health Packages"
Important: Do NOT display a browsable list/grid of all individual tests anywhere on the site by default. Tests should only appear when a user actively searches for them (in the search dropdown or a /search?q= results page). This keeps the homepage clean and search-driven. Health Packages ARE allowed to be shown openly on the homepage/Packages page (see section 7) since those are meant to be browsed and promoted.
Below the search bar, show a row of quick-search suggestion "chips" (e.g., "Thyroid Profile," "Diabetes Panel," "Full Body Checkup," "Vitamin D," "CBC") that populate the search bar on click.



Hero background: soft teal-to-white gradient with subtle abstract medical/lab-themed shapes (DNA strand line art, subtle molecule dots, a faint heartbeat line) — no stock photos of generic "doctors pointing at tablets." If using imagery, use a clean, warm photo of a real-feeling phlebotomist/lab professional or a home-collection visit.


6. UPLOAD PRESCRIPTION SECTION — CRITICAL FEATURE

Create a clearly visible, dedicated section (accessible from hero, nav, and its own page) titled something like "Have a Doctor's Prescription? Just Upload It — We'll Handle the Rest."


A polished drag-and-drop upload zone that also supports click-to-browse
Accepts images (JPG, PNG, HEIC) and PDF files, max size ~10MB, multiple files allowed
Show a live thumbnail/file-name preview after upload with a small "remove" (x) icon per file
Below the upload zone, a short contact form: Name, Phone Number, Preferred Address/Area (for home collection), Preferred Time Slot
On submit: a friendly success animation/confirmation ("Prescription received! Our team will call you within 30 minutes with a quote and available slots.")
Reassurance microcopy near the upload box about data privacy/confidentiality of medical documents
This flow should NOT require the user to know exact test names — it's designed for people who just have a doctor's handwritten/printed prescription and want the lab to interpret it

15. GENERAL REQUIREMENTS


Fully responsive across mobile, tablet, desktop — test at 375px, 768px, 1440px widths
Accessible: sufficient color contrast, alt text on icons/images, keyboard-navigable search and forms
Fast, smooth page transitions between routes
Consistent spacing/padding system (use a Tailwind spacing scale consistently)
No lorem-ipsum-looking placeholder — write real, professional, warm healthcare copy throughout (you can invent realistic details like accreditation numbers, stats, and testimonials since exact real data isn't provided — keep them clearly plausible and easy for me to edit later)
Use lucide-react or a similar clean icon set — no clashing icon styles
Avoid stock "corporate healthcare" clichés (no generic blue gradient hero with a stethoscope stock photo) — aim for a distinctive, premium, slightly editorial design feel


Build this as a complete, working, visually polished website — not just a wireframe. Prioritize the hero search bar, prescription upload flow, health packages display, and home-collection pricing logic as the four most important functional pieces.
